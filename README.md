# Komorebi House

An original cozy Japanese pixel-art room and garden customizer built with
Phaser 3 and TypeScript.

## Play

- Move with arrow keys, WASD, or the on-screen D-pad.
- Use **A / Enter / Space** to interact and **B / Escape** to cancel.
- Visit the room, garden, neighborhood kissaten, and riverside park.
- Earn Hikari through focus sessions, buy furnishings, and place, move,
  rotate, or store supported decor.
- Progress, furniture, audio preferences, and focus rewards save locally.

## Local development

```sh
npm install
npm run dev
```

The production artifact is generated with:

```sh
npm run build
```

All game art, names, characters, interface, and world layouts are original
clean-room work created for this project.
